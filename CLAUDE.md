# GBA WoW: notes for Claude

Private hobby GBA game (WoW-inspired open-world RPG), C++ with Butano. Roadmap and milestones are in
README.md.

## Build and check

- Submodule first: `git submodule update --init --depth 1` (Butano, pinned to a release tag).
- Build with Docker: `docker run --rm -v "$PWD":/src -w /src devkitpro/devkitarm make -j4`
  (in the cloud container, start the daemon with `sudo dockerd &` and prefix docker with sudo).
- Headless run + screenshots: `cc -O2 -o /tmp/mgba_script tools/headless/mgba_script.c -lmgba`
  (needs `libmgba-dev`), then e.g.
  `/tmp/mgba_script gba-wow.gba wait:30 hold:D:60 shot:/tmp/s.ppm` and look at the PPM.
- Always look at a screenshot after gameplay or art changes; CI uploads the same screenshots.

## Conventions

- Code: `gw_` file prefix, namespace `gw`, Butano style (snake_case, `_member` fields).
- No heap allocation in the game loop; use Butano containers and `bn::fixed`.
- World coordinates are pixels from the map's top-left; convert with `gw::world::to_screen_space`.
- Layers: ground BG priority 3, characters priority 2, overhead BG (tree tops, roofs) priority 1.
- Placeholder art is generated by `tools/gen_*.py`; edit the scripts, rerun them, commit the outputs.
- 4bpp backgrounds: every 8x8 tile must stay inside one 16-color bank and a background may use at
  most 1024 unique tiles; `gen_northshire.py` checks both.
